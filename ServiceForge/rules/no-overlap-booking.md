# No Overlapping Bookings

A technician cannot have two jobs with overlapping time windows. Before accepting a booking, check for a time conflict with the other jobs assigned to the same technician.

For example, if a technician already has a job from 10:00 to 11:00, a second job for that same technician from 10:30 to 11:30 must be rejected.

This conflict check applies to bookings for the same technician; it does not compare jobs assigned to different technicians.
